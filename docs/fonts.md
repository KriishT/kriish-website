# Fonts (Vantage)

Every face on the site, its licence and how it ships. No trial fonts are used.

| Family | Designer / foundry | Licence | Used for | Weights shipped | How it ships |
|---|---|---|---|---|---|
| Schibsted Grotesk | Bakken & Bæck for Schibsted | SIL Open Font License 1.1 | Painted headings, interface, statements | Variable 400–900, normal | Self-hosted by the Astro fonts API from Fontsource, Latin subset, `font-display: swap`, preloaded |
| Literata | TypeTogether | SIL Open Font License 1.1 | Reading text | Variable 300–700, normal and italic | Self-hosted by the Astro fonts API from Fontsource, Latin subset, `font-display: swap`, not preloaded |

Licences verified against Fontsource’s metadata (`license: OFL-1.1` for both) on 2026-10-20. The OFL allows use, embedding and self-hosting on a website, including commercially, without attribution on the page. It forbids selling the fonts by themselves.

Configuration: `astro.config.mjs` → `fonts`.
