## The problem

Architecture diagrams go stale the day they’re drawn. Trailmap draws the diagram from the code instead, and redraws it when the code changes.

## The system

- It scans a repository to find its services, databases and external dependencies, and renders them as a graph.
- Every connection carries the evidence it was inferred from and a confidence level, and links to the files that implement it.
- It re-scans on pushes to the default branch through GitHub webhooks, so the map stays current.
- It stores graph snapshots in Supabase and uses them to post dependency-impact summaries on pull requests.
